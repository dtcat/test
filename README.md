# 出差申请报告生成器

快速生成标准格式的出差申请和出差报告邮件的网页应用。

## 功能特性

- ✨ **双重模式**：支持出差申请和出差报告两种模式
- 📋 **标准格式**：生成符合企业标准的表格格式邮件
- 📱 **响应式设计**：完美适配桌面端和移动端设备
- 💾 **自动保存**：表单数据自动保存到本地存储
- 📋 **一键复制**：支持一键复制到剪贴板
- 🎨 **美观界面**：现代化的渐变色设计和流畅动画
- ✅ **表单验证**：实时验证确保数据完整性

## 使用方法

### 1. 打开应用

在浏览器中打开 `index.html` 文件即可使用。

### 2. 选择模式

点击顶部的标签页切换：
- **出差申请**：用于提交出差申请
- **出差报告**：用于提交出差总结报告

### 3. 填写表单

#### 出差申请需要填写：
- **基本信息**：姓名、部门、职位、联系方式
- **出差时间地点**：出发日期、返回日期、出差地点、交通方式
- **出差目的**：详细描述出差目的

#### 出差报告需要填写：
- **基本信息**：姓名、部门、职位、联系方式
- **出差信息**：出发日期、返回日期、出差地点、实际行程
- **出差目的回顾**：回顾出差的主要目的
- **出差总结**：描述工作成果、遇到的问题及建议

### 4. 生成预览

点击"生成预览"按钮，系统会自动验证表单数据并生成标准格式的邮件内容。

### 5. 复制内容

点击"复制到剪贴板"按钮，将生成的邮件内容复制到剪贴板，然后可以粘贴到邮件客户端中发送。

### 6. 清空表单

点击"清空表单"按钮可以清空当前表单的所有内容。

## 功能说明

### 表单验证

- 所有必填字段都不能为空
- 出发日期不能晚于返回日期
- 联系方式必须为有效的手机号码格式

### 数据保存

- 表单数据在输入时自动保存到浏览器本地存储
- 下次打开应用时会自动填充上次保存的数据
- 切换标签页时数据独立保存

### 复制功能

- 支持HTML格式复制，保持表格格式
- 如果浏览器不支持现代剪贴板API，会自动降级为文本复制
- 复制成功后会有提示消息

## 使用建议

1. **填写完整信息**：确保所有必填字段都已填写完整
2. **检查日期**：确认出发日期和返回日期的合理性
3. **详细描述**：出差目的和出差总结尽量详细具体
4. **及时复制**：生成预览后及时复制，避免页面刷新丢失内容

## 故障排除

**问题：复制功能不工作**
- 检查浏览器是否支持剪贴板API
- 尝试使用现代浏览器（Chrome、Firefox等）

**问题：数据没有自动保存**
- 检查浏览器是否允许使用localStorage
- 清除浏览器缓存后重试

**问题：表格格式显示不正确**
- 确保使用支持HTML格式的邮件客户端
- 尝试使用Outlook、Gmail等主流邮件客户端
